# Character creation

We need utilities and a (simple) agent to actually create valid player characters. Find out what is already shiped, how a character dataset should look like (schema), what the SRD rules say. (classes attributes, etc.). This needs to be separated in 3 Parts

* Model and Deterministic creation of character (check what is present now)
* Agentic creation (chat-alike on TUI or GUI)
* UI (the actual user facing chat for creating the character)
