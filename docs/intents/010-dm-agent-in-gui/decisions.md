# Decisions

One sentence each, in the product owner's words. `→ file` links an attachment in `decisions/`.

- D1: Play happens on its own screen, reached from the run screen by "Start adventure" or "Continue"; the run screen stays the lobby with campaign, party and adventure list, and going back returns there.
- D2: While the game waits for a specific answer or a roll, only the offered buttons work — choices as buttons, a roll as a "Roll" button the game rolls, never the model; free text returns as soon as the turn is open again.
- D3: The player sees a "the Dungeon Master is thinking" line with dice and questions appearing as they happen; the narration arrives in one piece at the end, never word by word.
- D4: A turn that fails halfway shows a line in the Dungeon Master's voice with "Try again"; everything already rolled or asked stays visible and counts.
- D5: After about 45 seconds the thinking line admits it is a long turn and keeps waiting; after about two minutes it becomes the in-voice failure with "Try again".
- D6: A player who left mid-turn finds everything that was recorded; a pending question or roll is still waiting, a lost narration simply means acting again — nothing is replayed for them.
- D7: The party rail beside the transcript shows each character's current and maximum hit points and armour class, updating as rolls land; initiative and conditions stay off the card, conditions appearing as system lines in the transcript instead.
- D8: The developer drawer — model, temperature, DM tone, turn and run cost — is its own intent after this one; this intent delivers play.
- D9: The campaign's ready-made hero is enough to start an adventure, so play does not wait for character creation; creating your own stays the better path once it ships.
- D10: The transcript shows everything the Dungeon Master does — rule lookups and state changes appear as small system lines between narration, actions, questions and rolls.
- D11: When an adventure ends the Dungeon Master narrates the ending, a clear end marker closes it in the transcript, and a button takes the player back to the lobby.
- D12: The play screen follows the attached flow, states, wording and narrow layout → decisions/D12-play-screen-flow.md.
- D13: Opening a brand-new adventure costs a Dungeon Master turn: the transcript is empty for a few seconds and the opening scene is written by the Dungeon Master, not printed from the campaign text.
- D14: No scene artwork in this intent; the transcript starts at the scene divider and the picture slot returns when real pictures exist.
- D15: Tapping a character in the party rail opens the full sheet over the transcript, and closing it returns to play.
