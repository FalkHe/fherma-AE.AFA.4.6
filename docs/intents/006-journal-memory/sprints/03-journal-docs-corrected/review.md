# Review: Sprint 03 — the docs describe the memory the product has

## What changed

The documentation described a memory the product does not have: a separate journal of curated facts, with the DM
writing entries into it. That was considered and dropped in favour of something simpler, and the docs now say so.
The DM's long-term memory is its own past narration — each line encoded as it is written, searched by meaning
across a whole campaign run. One memory tool is named where two used to be, and the journal survives only as the
alternative that was rejected — still available later if it turns out to be needed.

## How to check it

- Searching the general docs, the architecture overview and the 005 mechanics attachment for a journal, a journal
  entry or a fact-writing tool turns up nothing that presents them as part of the system.
- The model document says in one place what the DM's long-term memory is, and the passages that once argued for a
  separate journal now argue for what was built — inverted, not deleted.
- The known gap about memory now describes the real risk: something narrated as true can still come back after it
  has stopped being true, and what keeps that contained.

## Heads-up

- Changing the 005 mechanics attachment, which you own and approved, was authorised by this sprint's brief: it
  listed a tool the product no longer has.
- The briefs of earlier intents still mention a journal in their out-of-scope lists; those are history and were
  left as written.
